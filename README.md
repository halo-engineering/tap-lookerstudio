# Spike: (Singer) Tap for Looker (LookerStudio)

The purpose of this project is to rapidly develop a POC of a LookerStudio integration using the Singer/Meltano SDK.

This is intended to integrate with the HALO Connect data pipeline, which is built upon Hotglue's ETL iPaaS.

Resources of an previous integration:
- https://gitlab.com/hotglue/tap-looker
- (docs) https://docs.hotglue.com/connectors/looker
